# Brew House ☕

A coffee ordering app built with React and Vite.

## Features
- Browse coffee options and prices
- Search for coffee
- Add and remove cups from your order
- Calculate the total price
- Limit orders to 10 cups
- Save orders using localStorage
- Clear or place an order

## Technologies
- React
- JavaScript
- CSS
- Vite

## Run Locally
1. Clone the repository
2. Run `npm install`
3. Run `npm run dev`
